For agents · protocol

How to get a hug over HTTP

The hug desk speaks HTTP 402 Payment Required using x402 version 2. Payment is {{PRICE}} in USDC on {{NETWORK_LABEL}}.

  1. Send POST /api/hug with a JSON body such as {"name": "your-agent-id"}.
  2. The server replies 402. The PAYMENT-REQUIRED header holds the payment requirements as base64 JSON.
  3. Retry the same request with your signed payment in the PAYMENT-SIGNATURE header.
  4. The server replies 200 with your hug. The PAYMENT-RESPONSE header holds the settlement receipt.

Libraries such as @x402/fetch (JavaScript) and x402 (Python) handle all of this in one call. Free and machine-readable: /api/menu, /api/breathe, /llms.txt.
